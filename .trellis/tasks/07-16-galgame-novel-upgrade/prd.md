# Galgame-style Novel Upgrade

## Goal

把「死板自动续写」升级为 **可编辑角色卡 + 人物关系 + 真分支剧情树（自由导演）** 的互动写书体验，UI 改为 **粉紫糖果二次元、年轻化、动效灵动**；前端 **只维护 Vue SPA**。

## Confirmed Facts（仓库已验证）

- 技术栈：FastAPI + SQLAlchemy/SQLite + Vue3 SPA（`frontend/`）+ 遗留 Jinja（`app/templates`）。
- 人物设定为自由文本 `Novel.settings`；章节线性 `Chapter.index`；无角色/关系/分支。
- 生成：`generation.py` + `prompts.py` 黑箱续写；创建后自动大纲+第1章；APScheduler 定时续写。
- `init_db` 仅 `create_all`，无正式迁移框架；升级需自写 SQLite 兼容迁移或重建策略。
- Vue 开发端口 5173 代理 `/api`；生产 `frontend/dist` 尚未由 `main.py` 统一托管（当前仍挂 Jinja）。

## Requirements

### 角色与关系
- 角色 CRUD：姓名、别名、身份/定位、性格、外貌、背景、说话风格、备注、排序。
- 关系 CRUD：from→to、类型标签、描述。
- Prompt 注入全量角色卡 + 关系网；小说级保留 `premise` / `style` / 世界观文本（`world_setting`，可由旧 `settings` 迁入）。

### 剧情树（自由导演）
- 章节为树：`parent_id`（根为开篇，`parent_id=null`）。
- 节点字段：标题、正文、摘要、`plot_directive`（生成该节点时的用户指令）、`is_ending`、创建时间。
- 任意节点可：手写指令生成**子节点**；可选请求 AI 生成 2–4 条辅助选项（不强制）。
- 支持标记/取消结局；树总览切换当前阅读节点。
- **重生成**：默认对「当前节点」提供「用新指令重生成正文」（覆盖前确认）；「另开旁支」用生成子节点/兄弟节点流程，避免误删。
- 创建小说：用户可先建角色/世界观，再导演生成根节点（或一键「根据设定生成开篇」）；**不再**依赖定时任务。

### 生成与调度
- 移除 APScheduler 自动续写及 UI/API 上的 auto_continue 驱动逻辑。
- 保留 per-novel 生成锁；后台线程异步生成。
- Prompt 上下文 = 设定 + 角色 + 关系 + **根→父节点路径摘要** + 父章结尾 + 用户 `plot_directive`。

### UI
- 粉紫糖果二次元设计系统：渐变、玻璃拟态、大圆角、弹簧/浮动动效。
- 页面：书库、创建向导、小说工作台（阅读 / 剧情树 / 角色关系 / 导演台 / 模型设置）。
- 同色相深色模式可选。

### 前端与服务
- 仅 Vue SPA；`main.py` 托管 `frontend/dist`（API 优先，SPA fallback）。
- Jinja 路由与模板不再作为产品入口（可删除或仅 404/重定向）。

### 兼容
- 旧线性章节：按 `index` 链成单路径树（`parent_id` 指向前一章）。
- 旧 `settings` → `world_setting`；`auto_continue` 忽略。

## Acceptance Criteria

- [ ] 角色与关系可 CRUD，刷新后仍在。
- [ ] 章节树：同一父节点可有多个子节点；可从历史节点开旁支。
- [ ] 导演台：手写指令生成子节点；可选 AI 辅助选项。
- [ ] 可标记结局；树导航切换阅读节点。
- [ ] 生成 prompt 含角色、关系、路径上下文、剧情指令（抽测/日志可验证结构）。
- [ ] 无定时自动续写；无相关有效入口。
- [ ] UI 为粉紫糖果二次元风格，关键交互有灵动动效。
- [ ] 生产路径：构建 Vue 后由 FastAPI 提供 SPA；旧线性库可打开。
- [ ] Jinja 不再作为默认阅读/管理入口。

## Out of Scope

- 立绘 / CG / 语音 / BGM 资源管线。
- 多用户鉴权。
- 好感度、属性、条件锁选项。
- 定时/挂机自动续写。
- 原生移动 App。
- 完整 AVG 脚本语言。

## Research Notes

- SQLite 无 Alembic：用启动时轻量 `ALTER TABLE` / 数据回填迁移函数。
- `running_summary` 全局字段可废弃或仅作缓存；路径摘要按需从节点 `summary` 拼接。
- 创建流程建议改为：先落库设定与角色 → 用户在导演台生成根节点（避免黑箱自动写完第一章才给控制权）；若需「一键开篇」可作为可选按钮。
